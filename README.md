# P5. 영상 필터 설계 — 블러링과 샤프닝

3장에서 배운 **컨볼루션**을 2차원으로 확장해 영상에 적용합니다. 평균·가우시안 **저역통과 필터**로 잡음을 줄이는 블러링과,
**고역 강조**로 흐린 영상을 또렷하게 만드는 샤프닝(언샤프 마스킹)을 직접 구현하고,
커널 크기·σ·강조 계수에 따라 잡음 제거와 선명도가 어떻게 맞바뀌는지(트레이드오프) 정량적으로 분석합니다.
2차원 DFT로 각 필터의 주파수 응답을 그려 "왜 그렇게 동작하는지"를 설명하는 것이 핵심입니다.

## 2. 핵심 원리

- **2D 컨볼루션:** y[m, n] = Σᵢ Σⱼ h[i, j] · x[m − i, n − j] — 1D에서 배운 '접고, 밀고, 곱하고, 더하기'를 가로·세로로.
  출력 크기는 입력과 같게, 경계는 가장자리 화소를 복제해서 채웁니다.
- **블러링 = 저역통과:** 평균(box) 필터, 가우시안 필터 h[i, j] ∝ exp(−(i² + j²)/2σ²). 잡음(고주파)을 줄이지만 에지도 흐려집니다.
- **샤프닝 = 고역 강조:** 언샤프 마스킹 y = x + α·(x − blur(x)). (x − blur(x))가 고주파 성분이므로 α배 더해 에지를 살립니다.
  주파수 응답으로 보면 H = 1 + α(1 − G) — 저주파는 그대로, 고주파는 (1 + α)배.
- **분리 가능 커널:** 가우시안은 1D 커널의 외적이라 가로·세로 1D 컨볼루션 두 번으로 계산 가능 → 화소당 곱셈 K² → 2K.

## 5. 권장 파라미터 비교 실험 (공통 필수 요건)

| 파라미터 | 권장 범위 | 관찰할 지표와 해석 포인트 |
|---|---|---|
| 커널 크기 k (box) / σ (가우시안) | k = 3~9, σ = 0.5~3 | PSNR이 최대가 되는 지점 — 잡음 감소 ↔ 에지 흐려짐, 주파수 응답의 차단 주파수로 설명 |
| 필터 종류 | box vs 가우시안 | 같은 평활 정도에서 box의 부엽(주파수 응답의 sinc 모양)이 만드는 결함 |
| 잡음 종류 | 가우시안 vs 소금·후추 | 선형 필터의 한계와 메디안(비선형) 필터의 장점 |
| 강조 계수 α | 0.5 ~ 4 | 선명도 증가 ↔ 과도 강조(헤일로·잡음 증폭), PSNR 최적 α |
| 계산 방식 | 2D 직접 vs 분리형 (vs FFT) | 커널 크기에 따른 실행 시간 — 연산량 K² vs 2K |

**심화(선택):** 주파수 영역 필터링(FFT로 곱하기 — 이상적 저역통과의 링잉 관찰), 라플라시안 샤프닝, 에지 검출(Sobel),
잡음이 있는 영상의 샤프닝(잡음까지 증폭되는 문제와 해결), 컬러 영상 처리.
